## 2. โครงสร้างโจทย์ที่ดี (Stem Anatomy)

โจทย์ที่ดีควรยาว **2–4 บรรทัด** และเรียงตามลำดับ 3 ส่วนเสมอ:
1. **บริบท / เงื่อนไข (Premise):** กำหนดฟังก์ชัน, เซต, ข้อมูล, หรือสถานการณ์ประยุกต์สไตล์ สสวท. (ทุกตัวเลขที่ให้ต้องถูกนำไปใช้จริง ห้ามใส่ตัวเลขหลอกที่ไม่ได้ใช้)
2. **สมการ / ความสัมพันธ์ (Mathematical Core):** เขียนด้วย LaTeX มาตรฐาน KaTeX ครบคู่ `$...$`
3. **คำถามที่ชัดและมีคำตอบเดียว (Unambiguous Ask):** เช่น *"จงหาค่าของ $a + b$"*, *"ความน่าจะเป็นตรงกับข้อใด"*, *"มีข้อความที่ถูกต้องกี่ข้อ"*

### ตัวอย่างเปรียบเทียบ (Good vs. Bad)

| ❌ โจทย์ที่ต้องตีตก (Bad) | ✅ โจทย์มาตรฐาน สสวท. (Good) |
| :--- | :--- |
| ถาม *"เซตคำตอบของอสมการคือข้อใด"* แล้วตัวเลือกเป็น `(-2, 5)`, `[1, 4]` | ถาม *"ผลบวกของจำนวนเต็มทั้งหมดที่เป็นคำตอบของอสมการเท่ากับเท่าใด"* แล้วตัวเลือกเป็นตัวเลขเดี่ยว |
| ข้ออัตนัย (`numeric`) ได้คำตอบ `-4` (ฝนในกระดาษ `XXXX.XX` ไม่ได้!) | ข้ออัตนัย (`numeric`) ออกแบบให้ถาม $|b|$ หรือ $b^2$ หรือปรับพารามิเตอร์ให้คำตอบ $\ge 0$ และ $\le 9999.99$ |
| ตัวเลือกปรนัยสลับไปมาไม่เรียงลำดับ เช่น `12, 4, 20, 8, 16` | เรียงตัวเลือกจากน้อยไปมากเสมอ: `4, 8, 12, 16, 20` (ระบบ `sort_mcq_choices_ascending` จัดเรียงให้อัตโนมัติ) |
| ใช้ ASCII ในบทตรรกศาสตร์ เช่น `p -> q`, `p ^ ~r`, `q <-> r` | ใช้ LaTeX เต็มรูปแบบ: `$p \rightarrow q$`, `$p \land \sim r$`, `$q \leftrightarrow r$`, `$\forall x \in \mathbb{R}$` |

## 3. มาตรฐานตัวเลือกหลอก (Distractor Design)

ตัวเลือกหลอกทั้ง 4 ข้อในข้อปรนัยต้อง:
1. **ไม่ซ้ำกันทางคณิตศาสตร์** (ห้ามมีทั้ง `0.5` และ `$\frac{1}{2}$` ในข้อเดียวกัน — บังคับตรวจด้วย `verifier.py`)
2. **มีรูปแบบและหน่วยสม่ำเสมอกัน** (เช่น เศษส่วนอย่างต่ำเหมือนกัน หรือทศนิยมจำนวนตำแหน่งเท่ากัน)
3. **มาจากข้อผิดพลาดจริงของนักเรียน** เช่น ลืมหาร 2, ลืมเปลี่ยนเครื่องหมาย, แทนค่าจุดปลายช่วงโดยลืมเช็กจุดยอดพาราโบลา, หรือใช้ดอกเบี้ยเชิงเดียวแทนดอกเบี้ยทบต้น

## 4. มาตรฐานวิธีทำเฉลย (`solution_steps_th`)

- แบ่งขั้นตอนชัดเจน (`ขั้นที่ 1 ...`, `ขั้นที่ 2 ...`, `ขั้นที่ 3 ...`)
- **ห้ามแก้ตัวเลขจากโจทย์กลางทางเด็ดขาด** และห้ามมีข้อความขออภัย/เดาของ AI (ดักจับด้วย `RED_FLAG_PHRASES` ใน `verifier.py`)
- สรุปค่าคำตอบสุดท้ายให้ตรงกับ `sympy_computed_answer` และหมายเลขตัวเลือก 100%

## 5. กฎ Reverse-Engineering Construction (คิดจากคำตอบย้อนกลับไปเป็นโจทย์)

เพื่อป้องกันโจทย์ขัดแย้งกันเองใน 4 บทที่ผิดบ่อยที่สุด:
1. **ลำดับและอนุกรม:** กำหนดค่าจำนวนเต็ม `a1, d, b1, r, n` ก่อนแล้วคำนวณผลรวม `K` ทีหลัง; อนุกรมอนันต์ต้อง $|r| < 1$; เทเลสโคปิกต้องมีตัวประกอบ $\frac{1}{b-a}$
2. **ฟังก์ชัน:** พาราโบลาบนช่วงปิด $[x_1, x_2]$ ต้องเช็กทั้ง $f(x_1), f(x_2)$ และจุดยอด $x_v = -\frac{b}{2a}$ (ถ้าอยู่ในช่วง)
3. **ภาคตัดกรวย:** ใช้สามจำนวนพีทาโกรัส `(3,4,5)`, `(5,12,13)`, `(8,15,17)` — วงรี $a^2 = b^2 + c^2$, ไฮเพอร์โบลา $c^2 = a^2 + b^2$ และห้ามวางจุดบนไฮเพอร์โบลาตัดเส้นกำกับ
4. **เวกเตอร์ 3 มิติ:** กำหนดองค์ประกอบของ $\vec{u}, \vec{v}, \vec{w}$ ก่อนแล้วคำนวณ $|\vec{u} \times \vec{v}| > 0$ หรือ $|\vec{u} \cdot (\vec{v} \times \vec{w})| > 0$ ด้วย SymPy ก่อนเขียนโจทย์
